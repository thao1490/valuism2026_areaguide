2. Hosting Free on GitHub Pages for Mobile Attendees

  1. Create a Public repository on GitHub (for example, valuism2026-food-guide).
  2. Upload or paste this file as index.html into the root folder and commit changes.
  3. Go to Settings → Pages, select Deploy from a branch, choose main (/root), and click Save.
  4. Once live at https://<username>.github.io/<repo>/, generate a QR code for conference badges and slides to test on iOS and Android phones.
